# Privacy Policy

This application "Cpzenar" respects user privacy.  
Below is a description of how personal information is handled in this application.

## 1. Information Collected
- This application records text saved to the user's clipboard locally.
- **No internet communication is performed, and no data is sent to external servers.**
- **Internet connection is required only when sending support emails.**
- **Internet connection is required only when managing payments/licenses through Microsoft Store API.**

## 2. Purpose of Use
- Saved data is for the user's own management and use.
- Developers and third parties do not view or collect this data.

## 3. Third-Party Sharing
- This application does not provide user data to third parties.
- Support emails are sent using Gmail (Google) service.
